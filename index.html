V驗證流程線

轉乘 · Transfer to Verification Line

  1. V01需求理解

    先釐清業務流程、資料關係、模組邊界與錯誤情境。

  2. V02資料設計

    分層架構與 Repository / Service；重視資料一致，處理匯入匯出。

  3. V03API 實作

    ASP.NET Core Web API 與 RESTful API；控制修改範圍，保持模組化。

  4. V04測試

    以 TDD 驗證行為；修改既有 codebase 時補上必要測試。

  5. V05部署與維護

    排程、推播與補償排程；部署可控，錯誤可追蹤。

用 SDD 串起整條線：先寫規格再開發，讓需求、文件與程式碼對得上。我也持續研發 AI Workflow 工具，用 agent、skill 與知識圖譜降低理解程式碼的成本。
